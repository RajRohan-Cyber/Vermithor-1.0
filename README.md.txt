Vermithor 1.0

Vermithor 1.0 is a Python-based desktop voice assistant project.

This was an early version of the project, built to experiment with microphone input, speech recognition, voice responses, wake-word detection, basic commands, system information, and simple memory.

## Features

* Voice input
* Voice responses
* Wake-word detection
* Basic voice commands
* System commands
* Application commands
* Basic memory
* Microphone testing utilities

## Technologies

* Python
* Speech recognition
* Text-to-speech
* Audio processing
